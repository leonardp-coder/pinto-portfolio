# Pinto Leonard — Portfolio Website

A personal portfolio website showcasing data analytics, data engineering, and project case studies. Built with static HTML, CSS, and JavaScript.

## Pages and files

- `index.html` — Main portfolio homepage
- `about.html` — About page
- `bicycle.html` — Cycling / health analytics project page
- `Covid_case_study.html` — COVID case study project page
- `employee_cleaning.html` — Employee data cleaning project page
- `fifa.html` — FIFA analytics project page
- `get_in_touch.html` — Contact page
- `Project.html` — Projects directory page
- `retail_analytics.html` — Retail analytics project page
- `sales_performance.html` — Sales performance analytics project page
- `pinto-intro.js` — Intro animation / script shared by pages
- `README.md` — Project overview and setup notes

## Run locally

Open `index.html` in a browser. For a more reliable preview, run a static server from the portfolio folder:


```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish

This is a static website and does not require a backend or build step. It can be hosted using GitHub Pages or another static hosting service. Upload or push the website files and folders, preserving the file names and relative paths.


## Before publishing

- Confirm that all links and navigation paths use the exact file names (including capitalization).
- Ensure required images, fonts, scripts, and other assets are included.
- Check that contact information and any resume links are current.
- Review project descriptions and metrics for accuracy before making them public.
