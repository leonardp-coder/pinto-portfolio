Top Rated Players per Position (Window Ranking)

Uses DENSE_RANK() partitioned by primary position to isolate stand-out players without losing tie visibility.

01_top_by_position.sql ANSI SQL / CTE 
WITH ranked_players AS (
  SELECT
    player_name,
    nationality,
    best_position,
    overall_rating,
    potential_rating,
    DENSE_RANK() OVER (
      PARTITION BY best_position
      ORDER BY overall_rating DESC, potential_rating DESC
    ) AS pos_rank
  FROM fifa_players
  WHERE overall_rating IS NOT NULL
)
SELECT
  best_position,
  pos_rank,
  player_name,
  nationality,
  overall_rating,
  potential_rating
FROM ranked_players
WHERE pos_rank <= 3
ORDER BY best_position, pos_rank;
